## How to tick a book

1. Click the pencil icon (✏️) at the top right of this file.
2. Change `- [ ]` to `- [x]` on the line of the book you finished. You can add the date anywhere on that line, like `2026-11-20`.
3. To save a note, add a line right under the book, starting with two spaces: `  - Note: the one thing worth remembering`
4. Write a commit message like `Finished Wings of Fire` and click **Commit changes**.

Leave the hidden `<!-- tags -->` at the end of each line as they are. The page uses them to match books.

## Password

The first time you open the page, it asks you to choose a password and gives you a code. Paste that code into `password-hash.txt` in this repo and commit. After that, the page asks for the password. To change it, empty `password-hash.txt` and open the page again.

The password only guards the page. This repo is public, so this README (ticks and notes included) can still be read on GitHub.
