How to use this list
  • Go top to bottom. Core books are the ladder; bonus books are extras for when a level is going well.
  • If a book bores you after 50 pages, move to the next one. Forcing yourself through it is how reading habits die.
  • When you finish a book, tick it in README.md on GitHub (the “Tick books on GitHub” link opens it). Add a note under it for the one thing worth remembering. By 2028 those notes are your bank of examples for Essay and Ethics.
  • The newspaper starts at level 1 and never stops. Each level adds one more thing to your daily reading.
  • Dates are a guide. If you finish a level early, climb early.

On GitHub Pages, this page reads your ticks and notes from README.md in the repo, so it shows the same progress on every device. Changes can take a few minutes to appear. Opened as a file on your computer, it saves ticks in that browser instead.

Exam dates for 2028 are estimates from UPSC’s usual calendar. Check upsc.gov.in once the 2028 calendar is out.
